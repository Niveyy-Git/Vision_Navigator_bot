# Smart Voice Controlled Robot 🚗🤖

This project includes:
- Voice control using Bluetooth (HC-05)
- Obstacle avoidance using ultrasonic sensor
- Live camera streaming using ESP32-CAM through Mobile

## commands
F - Forward  
B - Back  
L - Left  
R - Right  
S - Stop  

## Features
✅ Voice Control  
✅ Obstacle Avoidance  
✅ Live Video Streaming

## Application
✅To develop a voice-controlled robot for real-time surveillance, assistance, and remote operation in practical environments.
